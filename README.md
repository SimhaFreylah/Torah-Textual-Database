# Torah-Textual-Database
Open Torah Textual Database  This repository contains a verse-level multilingual database of the Torah in Excel format.  
The dataset includes all 5,853 verses of:  
- Bereshit;
- Shemot;
- Vaikra;
- Bemidbar;
- Dvarim.

Included Data

The database contains:

Russian, English, and Hebrew texts
Masoretic verse references
Samaritan Torah readings
Septuagint (LXX) text
Literary source classification: J, E, P, H, D, Dtr, and R
Literary genre classification
Cross-references to the Tanakh, New Testament, Apocrypha, and Pseudepigrapha
Academic notes in Russian, English, and Hebrew
Parashah and chapter metadata
Source links and textual information
Purpose

The project is designed for:

biblical studies
textual criticism
literary and source criticism
digital humanities
database development
websites and research applications

Source classifications and academic notes represent scholarly reconstructions and should not be treated as manuscript annotations or universally accepted conclusions.
